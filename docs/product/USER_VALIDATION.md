# Try it with a campaign group

**Status:** session prepared; no external sessions recorded yet.

For a session in Spanish, use the [participant tasks and observation sheet](USER_SESSION_ES.md).

The question is simple: can a Game Master and two players find and check campaign information more easily than in their usual notes?

Start with one group. Record each participant's role and familiarity with the setting. If the first session exposes substantial usability problems, fix those before trying a second group.

## Twenty-minute session

Prepare a realm using the [demo guide](../operations/DEMO.md). Briefly explain the setting, then give these tasks without naming buttons or guiding the route. Note time, help needed, mistakes and any visibility problems.

1. Player: find where Lumbrevela is located and show the original wording.
2. Player: find a document by filename and read it without asking a question.
3. GM: add a private note, then reveal a separate spoiler to one player. Ask both players what they can see.
4. GM: replace a document and explain which version is available while it processes.
5. Player: follow an atlas relation to its character or place, then return.
6. GM: create a second campaign and return to the first.
7. Player: ask a question whose answer is absent and explain the result.

Repeat the first task with a comparable fact in the group's usual notes. Alternate which tool participants use first to reduce the effect of practice. The aim is to find problems in a small pilot, not estimate population-wide performance.

Afterward, ask what they would use next session, what would send them back to their existing notes, and what they thought a cited answer guaranteed.

Fix any information leak before releasing. Next, address tasks that repeatedly needed help. A useful first signal is that both players independently find and verify a fact, and the GM wants to use the archive in an upcoming session.

Write up the observations, failed tasks and next decision with a date. Ask permission before recording participants or publishing their words.
